## 构建与更新

```sh
python3 build.py
```

- framework.py：教育本质、课程设计、六种方法、难点与行动。
- visuals.py：原创概念补充、互动模型与课程闭环。
- lat.py：当前主读、照片目录、原创评析、树节点和教学案例。
- books.py：31项主题书目，区分正式中译、用户中文文本及未核实状态。
- content.py：保留历史、地图、认信与前期研究素材；并非所有素材均渲染进新版。
- app.js、styles.css：交互与响应式样式。
- land.json：Natural Earth公有领域底图。
- build.py：输出public/index.html与docs/index.html。

GitHub Pages从main的/docs发布；Vercel与Surge发布public目录。
Vercel通过授权API发布，目前尚未连接此仓库的Git自动部署。
不将密钥、密码、令牌写入源码或提交。
